# SmartStock Inventory System
## Release Notes — v2.0.1

### Overview

SmartStock v2.0.1 is a small maintenance release focused on desktop UI/UX polish.

### Fixed

- Reduced excessive unused vertical space in the desktop Inventory view.
- Reduced excessive unused vertical space in the Audit Log.
- Reduced excessive unused vertical space in the Supplier Directory.
- Improved use of available table and card space on larger displays.
- Improved selected navigation visibility: selected labels retain the SmartStock primary accent while selected icons remain clearly readable.
- Preserved responsive phone/tablet layouts while improving desktop presentation.

### Compatibility

- No intended database schema migration.
- Existing SmartStock inventory data remains compatible.
- Android and Linux remain supported by the shared Flutter codebase.
- iOS/iPadOS source remains part of the Flutter project; signed iOS builds require macOS and Xcode.

### Notes

This is intentionally a minor maintenance update. Larger stock automation features are planned separately.
